## 核心知识

### 1. 弥散渐变 = 各向异性高斯光斑 + 噪声扭曲

"极光"不是贴图，是 7 个各向异性高斯光斑的和：

```python
d  = rotate(p - center, angle) / (rx, ry)      # 各向异性：先旋转再按椭圆半径归一
g  = exp(-dot(d, d)) * intensity               # 每个光斑一个高斯
ws = Σg                                          # 权重和
acc = Σ color * g
col = mix(base, acc / ws, (1 - exp(-ws * 1.5)) ** 1.3) + acc * 0.07
```

三个关键细节，缺一个就"糊"：

- **不直接相加颜色**，而是 `acc / ws` 求加权平均，再用覆盖率曲线 `(1-e^{-ws·1.5})^{1.3}` 与原底色混合。直接相加会在光斑重叠处过曝成白斑，加权平均才能得到"光池"。
- **光斑重叠处要更热**：`core = smoothstep(0.75, 2.1, ws)`，重叠区额外提亮 22%。否则重叠区会被平均成灰。
- **先扭曲坐标再加光斑**：两层 fbm 把采样坐标推歪 150px（第二层幅度 30%），光斑边缘就有了有机的起伏——这就是"弥散"的来源。扭曲必须在光斑之前做。

光斑位置沿**闭合 Catmull-Rom 环**漂移（周期 24–40 秒，本片只截取 10 秒），再乘一点视差 `-cam * 0.35`，光场就有了纵深。

### 2. 玻璃拟态的三个数字：模糊 + 饱和度 170% + 7% 白

磨砂玻璃的配方简单到反直觉，但三个数字都要对：

```python
bb = blur(background, 28px)            # ① 背景模糊
l  = luma(bb)
bb = max(l + (bb - l) * 1.38, 0)       # ② 饱和度拉到 138%（不是 100%！）
col = bb * 1.02 + 0.056 + (0.012, 0.012, 0.03)   # ③ 抬 5.6% 白 + 一丝冷色偏
```

- **为什么要提饱和**：模糊本身就是低通滤波，视觉上会"变灰"。拉高饱和度是补偿。
- **为什么加白**：真实磨砂玻璃会把一部分环境光散射进眼睛。纯透射的玻璃看起来像塑料片。
- **冷色偏**：`(0.012, 0.012, 0.03)` 让玻璃在高光处偏蓝，是"光学玻璃"而非"塑料"的暗示。

### 3. 边缘折射：厚度场

玻璃是有厚度的，边缘会把背后的画面**向内拉**。用圆角矩形的 SDF 算"离边缘多少像素"，再按这个距离做位移：

```python
inside = -sd / pxw                      # 离边缘的屏幕像素数
rim    = 1 - smoothstep(0, 13, inside)  # 边缘 13px 内为 1
offs   = -normal * rim ** 1.3 * 24      # 最多往内拉 24px
bb     = sample(blurred_bg, p + offs)   # 采样被拉过的背景
```

`rim ** 1.3` 这个指数是旋钮：指数越大，折射越集中在最外侧一圈。**没有这一步，玻璃就是一张半透明贴纸**——这是玻璃拟态和"透明度 20% 的矩形"之间最大的区别。

法线用圆角矩形 SDF 解析求导得到（`abs(L) - half + r` 的梯度），不需要任何贴图。

### 4. 1px 内描边与斜向高光：玻璃的"边"从哪来

真实玻璃的轮廓来自**边缘的菲涅尔反射**——正对着看是透明的，掠射角看是亮的。用 `facing = dot(normal, light)` 近似：

```python
sw     = 0.9 + (defocus - 0.5) * 1.5        # 描边宽度随失焦变宽
stroke = clamp(1 - abs(inside - sw) / sw, 0, 1) * (0.9 / sw)
sa     = mix(0.14, 0.70, facing ** 1.6)     # 受光侧 70% 白，背光侧 14%
col    = mix(col, white, stroke * sa)
```

再加两道高光：一道**沿对角线的宽带柔光**（模拟柔光箱的反射），一道**细窄的滑行掠光**（高光沿对角线扫过卡面）。两者都是 `exp(-((band - pos)/w)^2)`，只是宽度差 3 倍——宽的是"环境"，窄的是"事件"。

### 5. 液态玻璃透镜：7 次采样做光谱色散

透镜是**同一段代码**从 14px 的珠子长到 132×86 的镜片，再收成句号环。核心是折射：

```python
N  = normalize(-dh/dx * depth, -dh/dy * depth, 1)   # 厚度场求法线
for i in 0..6:
    ior = 1.42 + 0.055 * k                          # k: +1 紫 → -1 红
    R   = refract(I, N, 1/ior)                      # 斯涅尔折射
    disp = R.xy / -R.z * depth                      # 位移
    acc += sample(scene, C + (p-C)/mag + disp) * SW[i]   # 7 个谱段加权叠加
```

- **7 个谱段各算一次折射**：因为折射率随波长变化（色散），红绿紫的偏移量不同。7 次采样的权重表 `SW` 之和为 1，得到的是带彩色边缘的折射像。
- **厚度场用凸方圆形**：`h = (1 - (1-x)^2.2)^(1/2.2)`，`x` 是离边缘的距离归一化。这个超椭圆让镜片"平顶 + 圆倒角"，比球冠更像真实玻璃。
- **菲涅尔 + 主光镜面 + 环境反弹**：`F = (1-N.z)^1.6` 控制边缘反射强度；两个 Blinn-Phong 高光（主光左上、环境右下）给出体积感。

### 6. 磨砂玻璃字形：把字标当玻璃物件渲染

字标不是画上去的，是**用字形遮罩当厚度图**渲染出来的玻璃实体：

```python
hN = blur(mask, 5px)              # 窄模糊 → 倒角高度场
hW = blur(down4(mask), 6px)       # 宽模糊 → 圆顶 + 投影
slope = -(∇hN * 7.5 + ∇hW * 5)    # 两级坡度合成表面法线
fr = 磨砂极光在 (p + slope * 30px) 处采样   # 玻璃体 = 被折射的极光
```

然后是四道"玻璃感"：

| 现象 | 做法 |
|---|---|
| 受光倒角反射光 | `bev * facing^1.7` |
| 背光倒角吸暗 | `1 - 0.5 * bev * (-facing)^1.1` |
| 焦散：光穿过玻璃聚焦在内侧远边 | `band(0.34..0.72) * (-facing)^2` |
| 1~2px 镜面边线 | `mix(col, white, band_e * (0.22 + 0.7*facing^1.4))` |

R/G/B 三个通道用**略微不同的折射偏移**采样（`offs * 1.08 / 1.0 / 0.92`），边缘就有了色散——这是让"玻璃字"看起来真的是一块玻璃而不是白色贴纸的关键。

### 7. 电影后期：bloom / 颗粒 / 抖动

```python
q = down4(scene); q *= smoothstep(0.58, 0.95, luma(q))   # 阈值提取亮部
bloom = upsample(blur(q, 9px))                            # 大半径模糊
c = scene + bloom * amount                                # 加性合成
hi = max(c - 0.82, 0); c = c - hi + hi / (1 + hi * 2.2)   # 高光肩部，防死白
c += grain(frame_seed) * 0.055 * (0.55 + 0.9*l*(1.4-l))   # 中间调更明显的胶片颗粒
c += dither(pixel, frame) / 255                           # 三角抖动，消色带
```

- **bloom 在 1/4 分辨率算**：模糊半径 9px（等效全分辨率 36px），成本降到 1/16。
- **颗粒强度随亮度变化** `(0.55 + 0.9·l·(1.4-l))`：中间调颗粒最重，纯黑纯白最干净——这是胶片的行为，均匀叠加的噪声看起来像数字噪声。
- **抖动必须做**：渐变视频在 8bit 下会出现明显的色带（banding），加 1/255 的三角噪声就没了。

### 8. 工程：在 15.7GB 内存的机器上渲染 600 帧 1080p

这一版最硬的约束不是算法而是内存（实测可用仅 1.3–1.8GB）。四条规矩：

1. **光场跑 1/2 分辨率**：弥散渐变是低频信号，降采样肉眼无差，成本降到 1/4，再双线性拉回全分辨率。
2. **所有全分辨率 pass 走包围盒**：卡片、透镜、字标各自算出投影包围盒，只在盒内计算。字标 pass 从 2.07M 像素降到 0.5M。
3. **`sample()` 用就地运算**：双线性采样从 7 个临时数组降到 4 个（`b -= a; b *= fx; b += a`）。全分辨率下每个临时数组就是 25MB。
4. **float32 纪律**：`np.float64` 的临时数组是内存杀手。`mix/clip/f32` 全部强制 float32，避免 `float32 ** 1.4` 悄悄升成 float64。

另外两个坑（踩了才知道）：

- **PIL 的 float 缩放不可靠**：`np.asarray(pil_image)` 返回的是 PIL 内部缓冲的**视图**，临时图一释放就是悬垂指针，读出来是 `2e38` 和 `NaN`。且同一输入时好时坏（取决于内存是否被复用）。最终换成纯 numpy 的可分离双线性，确定性优先。
- **盒式模糊 ×3 ≈ 高斯**：`cumsum` 差分实现，O(n) 且与半径无关，比 FFT 更适合小半径多次调用。

## 运行

```bash
# 关键帧预览（10 张 prev_*.png）
python make_aurora.py preview

# 单帧
python make_aurora.py one 6.0 frame.png

# 全部 600 帧（多进程；内存紧就调小并发数）
python make_aurora.py all 3

# 编码
ffmpeg -y -framerate 60 -i frames/f_%04d.png -c:v libx264 -preset slow -crf 17 \
       -pix_fmt yuv420p -movflags +faststart output.mp4
```

值得玩的参数：`BLOBS` 的光斑颜色/半径/漂移环、`WARP`（扭曲幅度，150 → 300 会变成"液态金属"）、`rim ** 1.3 * 24`（边缘折射）、`FOCAL`（焦距，改小透视更夸张）、`MAG` 与 `MAXD`（透镜放大率与色散量）。
