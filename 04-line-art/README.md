# 04 · 线条动画 Line Art

> 线就是全部画面，留白一样重要。一根金线全程不离纸，从一粒种子画到一座城、一轮日。
> 本目录：单条连续路径的描边动画，60fps，8 秒一镜到底。

[▶ 成片 output.mp4](output.mp4) · 脚本 [make_lineart.py](make_lineart.py)

## 核心知识

### 1. SVG 描边动画的原理（先懂网页版，再懂代码版）

网页上的描边动画只靠两个属性：

- `stroke-dasharray`：把虚线段的"实段"设为路径总长 → 路径看起来是完整实线
- `stroke-dashoffset`：把虚线"偏移"从总长动画到 0 → 实线从起点逐渐"画出来"

本质是**按弧长揭示路径**。本目录用代码复刻同一件事：把整条路径均匀采样成点列，每帧绘制"前 p×总弧长"个点。

### 2. 弧长参数化：把任意路径变成一条点队列

路径 = 基元序列（直线 / 三次贝塞尔 / 圆弧 / 螺旋），每个基元按约 3px 步长采样成点，首尾相接成**一条点队列**。此后"画到哪了"只是一个下标：

```python
idx  = progress * (len(points) - 1)      # 进度 ∈ [0,1] → 队列位置
pts  = points[:int(idx)] + [插值出的笔尖]  # 亚像素平滑
```

进度随时间用 easeInOutSine——起笔收笔慢、中间匀速，像真人运笔。

### 3. 贝塞尔曲线 30 秒入门

三次贝塞尔 = 起点、两个控制点、终点，点由公式 `(1-u)³P0 + 3u(1-u)²P1 + 3u²(1-u)P2 + u³P3` 给出。控制点像"磁铁"，把曲线往自己方向拽。本片的种子螺旋出口、茎叶过渡、收笔回环、高空甩线全是贝塞尔——**自由曲线全靠它，直线反而是它的退化情形**。

### 4. 一笔画的设计约束（本片调了三版才干净）

"笔不离纸"意味着所有形状共享一条路径，于是：

- **任何交叉都是永久的**：第一版太阳圆环从天线尖里穿过、第二版叶环与下降线交叉，都只能改构图解决
- 规则化布局：叶环全部放在茎的同一侧、下降线走另一侧；天线压短给太阳让位
- 环形"叶子"= 笔在原地绕一整圈回到交点（一笔画里画圆叶的经典手法）
- 自交不是禁区：收笔的回环故意与地面线交叉一次，那是"签名式"的设计

### 5. 廉价而有效的呈现细节

- **双层描边**：先画 9px 暗金宽线，再画 2.6px 亮金细线 → 深底上的"辉光"零成本
- **笔尖亮点**：当前画到的位置加一枚亮色小圆 + 一圈细环，观众视线自动跟着运笔
- **收尾灌金**：圆日路径闭合后，磁盘半径用 easeOutBack 从 0 长到满——线条叙事的最后一下"落锤"

## 运行

```bash
python make_lineart.py preview   # 抽 6 帧预览
python make_lineart.py all       # 480 帧（60fps×8s）到 frames/
ffmpeg -y -framerate 60 -i frames/f_%04d.png -c:v libx264 -preset slow -crf 17 \
       -pix_fmt yuv420p -movflags +faststart output.mp4
```

值得玩的参数：`T_DRAW` 描线总时长、`SUN`/天际线坐标、金线宽度与双层辉光、填充缓动。

## 延伸

- CSS/SVG 的 `stroke-dasharray` + `stroke-dashoffset`：网页上做同款
- AE 的 Trim Paths：影视包装里描边动画的标准工具
- 关键词：one line drawing / continuous line art
