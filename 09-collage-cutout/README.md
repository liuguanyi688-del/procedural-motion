# 09 · 拼贴剪贴 Collage · Cut-out

> 剪报、牛皮纸、网点印刷，12 fps 的卡顿也是风格。绅士照被剪开脑袋，脑洞蹦了出来。
> 本目录：牛皮纸底 + 报纸剪块 + 半调网点绅士——剪开脑袋，星云连 BANG! 一起蹦出来。12fps 逐格步进。

[▶ 成片 output.mp4](output.mp4) · 脚本 [make_collage.py](make_collage.py)

## 核心知识

### 1. 零素材拼贴：所有"剪贴素材"都是程序生成的

没有一张外部图片——全部程序生成再"剪"出来：

| 素材 | 生成方式 |
|---|---|
| 牛皮纸底 | 棕色底 + 逐像素噪声 + 240 条随机纸纤维 |
| 报纸剪块 | 浅灰底 + 7 栏伪文字（随机长度的灰色短杠）+ 四边锯齿撕边蒙版 |
| 绅士肖像 | 形状分层绘制（大衣/领子/头/五官）后**半调网点化** |
| 星云 | 多色软斑块叠加 + 星点，再网点化 |

### 2. 半调网点（halftone）：复古印刷感的来源

```python
def dotize(img, cell, bg):
    small = img.resize((w//cell, h//cell))       # 降采样取均色
    每格画一个半径 0.52×cell 的圆, 颜色 = 均色, 底 = 纸色
```

把任何图像变成"印在纸上的网点"——肖像、星云都过一遍，插画风立刻统一。格子尺寸是风格旋钮：cell 越大越粗犷。

### 3. 撕边与缝线：不完美即真实

- **撕边**：所有纸片的 alpha 蒙版都是四边锯齿的多边形（`paper_mask`：沿每边随机抖动 ±9px）——规则矩形一眼假
- **裁切线**：头脑开口用单边锯齿蒙版切成上下两片
- **缝线**：沿锯齿边每隔一段画一条**垂直于边**的短线（suture 角度 = 边切线角 + 90°），外科缝合感

### 4. 12fps 逐格步进：卡顿即风格

```python
def step(t): return floor(t * 12) / 12       # 时间量化到 1/12 秒
```

所有运动（蹦出、漂浮、BANG 弹入）都用步进时间驱动，再以 120 帧渲染、容器 60fps 每帧×5。**逐格的顿挫就是剪纸动画的"手作感"**——60fps 的丝滑反而毁风格（与 03/07 的结论正好相反：帧率服务于风格）。

### 5. 叙事时间轴（12fps 步进）

| 时间 | 事件 |
|---|---|
| 0-1.6s | 静态拼贴：绅士 + 报纸 + 红圆，纸张微颤 |
| 1.6-2.6s | 裁切虚线沿额头推进，缝线逐段出现 |
| 2.6-3.2s | 头顶片掀起（旋转+淡出），露出红圆与黑洞 |
| 3.2-4.0s | 星云从洞里弹跳长大（半调网点化） |
| 4.0-5.4s | 星星/纸片/网点圆逐格蹦出，步进漂浮 |
| 5.4-6.2s | BANG! 勒索信字母逐个砸入（黑白红三色、各自歪斜） |
| 6.6s+ | №06 红贴纸旋转盖印，全部元素步进漂浮到结束 |

## 运行

```bash
python make_collage.py preview   # 12 帧预览
python make_collage.py all       # 120 帧到 frames/
ffmpeg -y -framerate 12 -i frames/f_%04d.png -c:v libx264 -preset slow -crf 17 \
       -pix_fmt yuv420p -r 60 -movflags +faststart output.mp4
```

值得玩的参数：`dotize` 的 cell、撕边幅度、星云 blob 配色、BANG 字母的颜色/角度表、`STEP_FPS`（试试 8 更卡、16 更顺）。
