# 13 · 像素风 Pixel Art — PIXEL QUEST 像素冒险

> 320×180 的索引色画布，32 色母版，128 个语义槽。从清晨一路走到星夜，
> **画面上没有一个像素被重画过**——变的是色号，不是画。

本目录：1920×1080 / 60fps / 10 秒 / **150 BPM**（一拍 0.4 秒）。

[▶ 成片 output.mp4](output.mp4) · 脚本 [make_pixel.py](make_pixel.py)

> 参考坐标：`mg-styles-15` 的 `20-pixel`（Canvas2D 索引色 + WebGL CRT）。
> 这里是同一套索引色管线的纯 Python 复刻——没有 canvas、没有着色器。

## 核心知识

### 1. 索引色：整片的地基

画面里每个像素只存一个**色号**（0–127），不是 RGB。

```python
IW, IH = 320, 180          # 低分辨率画布
SCALE  = 6                 # 整数放大 6 倍 → 1920×1080
```

放大必须用 `Image.NEAREST`——像素画的全部美感来自硬边，任何插值都会把它毁掉。

### 2. 语义槽 + 每帧 LUT

128 个槽分成两段：

- **0–63 语义槽**：`s0..s4`（天空五带）、`sun`/`sunG`（日月）、`clL`/`clD`（云）、
  `mD`/`mL`/`mS`（远山）、`rD`/`rM`/`rL`（岩壁）、`fD`/`fM`/`fL`（森林）、
  `hD`/`hM`/`hL`（灌木）、`gD`/`gM`/`gL`（草地）、`dD`/`dM`/`dL`（泥地）……
  ——画的时候写的是**"这是什么"**，不是"这是什么颜色"
- **64–95 直接色**：固定映射到母版 0–31，精灵专用

每个语义槽存**六个色号**，六个时段各一个：

```python
env('s0',  [4, 4, 3, 3, 2, 1])
#          DAY AFT GOLD SUNS DUSK NIGHT
env('clL', [8, 8, 15, 13, 11, 3])
```

每帧生成一张 LUT，把语义槽翻译成真实色号：

```python
def make_lut(f):
    a, b, t = stage_of(f)
    lut[s] = mix_idx(SM[s][a], SM[s][b], t) if t else SM[s][a]
```

`mix_idx` 在**母版空间**里插值——取两个色号的实际 RGB 混一下，再找母版里最接近的那个色。
这样过渡永远不会跑到调色板外面去（否则会出现"不属于这张图的颜色"）。

### 3. 调色板轮换：水波和星星不画，只转色号

这是全片最漂亮的一招。

水面波纹的**像素位置永远不动**，动的只是它们引用的色号：

```python
ph = f // 3                       # 10 fps
for k in range(4):
    lut[WS[k]] = mix_idx(SM[WS[(k - ph) & 3]][a], SM[WS[(k - ph) & 3]][b], t)
```

`WS` 是 4 个水波槽，每 3 帧把色号整体往前轮一格——水就流起来了，**一个像素都没重画**。
这是一种几乎零成本的动画，NES 时代的水面就是这么做的。

星星同理，7.5fps 轮换（`sp = f // 4`），于是星星在闪。
瀑布用两层各 8 槽的相位序列（`WFSEQ`），流速是水波的两倍。

### 4. 六个时段：一整天只用一张画

| 时段 | 时间 | 观感 |
|---|---|---|
| DAY | 0.0s | 天蓝、白云、正午 |
| AFTERNOON | 1.6s | 稍暖 |
| GOLDEN | 3.2s | 金色斜阳，云变橙 |
| SUNSET | 4.4s | 紫红天，远山成剪影 |
| DUSK | 6.4s | 暮色（紧接宝箱白闪） |
| NIGHT | 8.0s | 深蓝星空 + 浅蓝月亮 |

时段之间用 4 帧过渡：前 2 帧混 1/3，后 2 帧混 2/3。

天空五条色带的边界用 **4×4 有序抖动**过渡（`bay(x, y)` 是 Bayer 矩阵）：

```python
for y in range(yb - 3, yb + 3):
    for x in range(IW):
        if (bay(x, y) < 0.5) != (y >= yb):
            b.px(x, y, 上带 if y >= yb else 下带)
```

这是像素画里最经典的渐变手法——**不做真渐变，用棋盘格交错两个色号**，人眼会自动把它读成中间色。
真做渐变反而"不像像素画"。

### 5. 分层视差

远山 / 中景 / 灌木各按不同比例跟相机走：

```python
blit_layer(b, MT,    int(cx * 0.125), ...)   # 远山最慢
blit_layer(b, MID,   int(cx * 0.30),  ...)
blit_layer(b, HILLS, int(cx * 0.55),  ...)   # 近景最快
```

云更慢（0.12）。每一层都是**预计算一次的 420px 宽循环条带**，运行时只做水平取模偏移——
`((x - off) % 420 + 420) % 420 - 50`，两个取模是为了处理负偏移。

### 6. 世界状态全是闭式函数

没有物理引擎，没有状态机。相机、主角高度、宝箱、得分，都是**帧号的纯函数**：

```python
def hx(f):           # 主角世界 x：跑 → 刹车（SKID 表 13 帧）→ 停
def cam_x(f):        # 相机：跟随，到 CAM_END 后停住，让主角自己走出画面
def hero_h(f):       # 跳跃：抛物线 s(1-s)，两段不同高度
def bridge_sag(wx):  # 木桥下垂：2·sin(π·(wx-x0)/(x1-x0))
def score_at(f):     # 得分：数一数已经过了几个金币
```

好处是**可以跳到任意一帧直接渲染**，不需要从头模拟——多进程渲染才能随便拆段。

### 7. CRT 合成

320×180 → NEAREST 放大 6 倍 → 三道 CRT 处理：

```python
k    = 1 + 0.032·r² + 0.012·r⁴            # 桶形畸变（出屏即黑）
scan = 1 - 0.30·exp(-((row - 3)²) / 1.1)  # 扫描线：每 6 个输出行一组
mask[..., ch] = 1.22 / 0.62               # 荫罩：每 3 个输出列循环 R/G/B
vig  = 1 - 0.42·(r² · 0.62)^1.3           # 暗角
```

**扫描线周期必须等于放大倍数（6）**，这样每 6 个输出行正好对应 1 个源行；
周期不整除就会出现摩尔纹，整片都会"脏"。

开头 0.35 秒是开机：画面从中间一条横线向上下展开（`line = exp(-(y-H/2)²/60)`）。

## 运行

```bash
# 关键帧预览
python make_pixel.py preview

# 单帧
python make_pixel.py one 9.5 frame.png

# 全部 600 帧（这一版很快，约 1 分钟）
python make_pixel.py all 4

# 只渲某一段（多进程）
python make_pixel.py range 480 600 4

# 编码（像素画是硬边，x264 效率很高；扫描线是高频纹理，crf 18 是平衡点）
ffmpeg -y -framerate 60 -i frames/f_%04d.png -c:v libx264 -preset slower -crf 18 \
       -pix_fmt yuv420p -movflags +faststart output.mp4
```

值得玩的参数：

- `HEX` 的 32 色母版——整片的色彩性格全在这 32 行里，换一套就是另一台机器
- `env()` 的六列时段色号——把 NIGHT 列改成暖色就是"篝火夜晚"
- `WFSEQ` 的瀑布相位序列——换顺序就换水流方向

## 工程注记

这一版是 15 个里**最快的**：600 帧不到 1 分钟。原因是画布只有 320×180，
逐像素循环的规模是 1080p 的 **1/36**。

三个坑：

- **`np.where` 两个标量参数会升成 float64**（12 号也踩过同一个坑）。
  1920×1080×3 下一次隐藏分配就是 47.5MB，多进程直接爆。逐像素一律写 `np.float32(...)`。
- **`stage_of` 漏了 NIGHT 分支**：脚本定义了六个时段，分支却只写到 4，
  于是 8.0s 之后一直停在暮色列，**NIGHT 整列成了死代码**。
  画面上不明显（暮色也是深色），补上之后 8.0s 起才是真正的深蓝星空。
- **光效半径必须留在画布内**：开箱星芒原本半径最大 190px，在 320×180 上等于全屏扫射，
  把主角和 logo 一起吞掉了。收到 78px 之后才读得出"光是从宝箱里发出来的"。
