## 核心知识

### 1. 超大画布 + 相机 = "运镜"的本质

所有内容画在一张 3200×2000 的大画布上（成片 1600×1000 的两倍），"运镜"就是**一个动画裁剪窗口**：

```python
def camera(t):
    # 漂移 → 推进到屏幕(1500 宽) → 微推 → 拉远回全景
    return (x0, y0, x1, y1)      # 宽高比锁定 1.6
canvas.crop(rect).resize((1600, 1000))
```

推拉的节奏：慢漂移(3s) → 加速推进(1.6s) → 目标处继续微推(2.8s) → 拉远(1.6s)。**运镜的质感来自速度曲线**（easeInOut）和"推进后继续微推"的余韵，而不是移动本身。

### 2. 贴纸感 = 三层结构

每个贴纸图形由三层叠加：

1. **投影层**：同形状偏移 (26, 30)，浅灰色——"贴在墙上"的浮起感
2. **白边层**：形状外扩 10~18px 的纯白底——粗白描边
3. **内容层**：本体填充

文字贴纸同理。加上点阵背景（62px 网格灰点）和虚线占位框，"科普排版"的质感就齐了。

### 3. 贴纸里的图表：SVG 图表的代码版

屏幕内的"机身质量占比"是纯代码图表：圆角条形 + 左侧标签列 + easeOutBack 生长动画（`bw × a`）。数据、配色、位置全是常量表——改数据就是改一个列表。

### 4. 层次即叙事：画家算法的排序

绘制顺序 = 叙事顺序：背景点阵 → 标题卡 → 手机贴纸 → 屏幕内 UI → 相机裁剪。推进到屏幕后，屏幕内 UI 直接"长"在屏幕坐标系里（画布坐标），相机推到位自然露出——**不需要为特写单独做一套画面**，这就是超大画布方案的核心优势。

### 5. 排坑

- **相机比例锁死**：裁剪窗口宽高比必须恒等于成片比（1.6），否则推拉过程中画面会变形
- **屏幕内 UI 的边界**：屏幕内图表的布局要按"裁剪后可见范围"设计，本片图表第一版溢出屏幕边框——裁剪救不了画到界外的东西
- 字体在画布坐标直接渲染（尺寸 ×2），最终缩放后自然清晰

## 运行

```bash
python make_sticker.py preview   # 7 帧预览
python make_sticker.py all       # 600 帧（10s × 60fps）到 frames/
ffmpeg -y -framerate 60 -i frames/f_%04d.png -c:v libx264 -preset slow -crf 17 \
       -pix_fmt yuv420p -movflags +faststart output.mp4
```

值得玩的参数：`camera()` 的关键帧与时长、贴纸层厚 `out_w`、点阵密度、元素贴纸表、图表数据。
